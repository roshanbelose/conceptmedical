# Concept Medical

This repository contains Concept Medical design/prototype assets.

## Product Line Executive Dashboard

An executive-level **Product Line Performance Dashboard** for medical-device
manufacturing (DCB / DES portfolio) — a redesign of the basic
*"Production Line Capacity by Product"* chart into a full command-center view
with KPIs, capacity, utilization, product mix, 12-month trend, quality/yield,
and OEE.

- **Open:** [`dashboard/index.html`](dashboard/index.html) — self-contained, no build step.
- **Docs:** [`dashboard/README.md`](dashboard/README.md) — chart specs, Power BI
  visual mapping, UX rationale, data model, and wireframe.
